# CryptoRebate Logo Redesign Brief

## 1. Project Context

- Brand: **CryptoRebate**
- Product type: crypto exchange rebate comparison site
- Core promise: **compare rebates before registering, so users save more on trading fees over time**
- Primary job of the logo: make the product feel **trustworthy, clear, conversion-oriented, and not like a low-quality affiliate site**

## 2. Why redesign now

Current mark (`web/public/images/brand/cryptorebate-mark.svg`) already communicates:
- blue = finance / trust / web product
- yellow arrow = savings / uplift / rebate
- rounded square = app icon friendliness

But the current mark still feels closer to a **generic fintech app badge** than a differentiated **crypto rebate comparison brand**.

Main gaps:
1. **Recognition is weak** — not memorable enough on first glance.
2. **Meaning is split** — the arrow and inner form do not yet read as one strong idea.
3. **Trust signal is only medium** — good enough for a draft, not yet strong enough for a site asking users to click outbound exchange links.
4. **Brand personality is under-defined** — it says “finance app”, but not clearly “smart fee savings / compare-before-you-click / crypto utility”.

## 3. Brand positioning the logo must support

The logo should support this product positioning:

> CryptoRebate is not a noisy coupon farm.
> It is a clean, credible, comparison-first decision tool for crypto traders who want to reduce fee drag.

Logo should therefore feel:
- **credible** rather than hype-driven
- **sharp** rather than playful
- **efficient** rather than decorative
- **global internet product** rather than local campaign page
- **crypto-native enough**, but not full of clichés

## 4. Target user impression

When a user sees the logo in the top-left corner, favicon, social card, or app icon, the intended reaction is:

- “This looks reliable.”
- “This is a product, not a spammy affiliate page.”
- “It probably helps me compare costs clearly.”
- “It feels modern and internet-native.”

## 5. Core visual message

The new logo should combine at least **2 of these 3 ideas** in a single simple system:

1. **Rebate / savings / return**
   - cashback
   - fee reduction
   - money flowing back

2. **Comparison / selection / decision**
   - side-by-side evaluation
   - filtering
   - picking the better route

3. **Crypto / trading / exchange infrastructure**
   - markets
   - trading pathways
   - exchange ecosystem

Important: do **not** make it look like a token logo, meme coin, or exchange logo clone.

## 6. Design direction

### Desired direction

- geometric and clean
- simple enough for favicon use
- compact, high-recognition silhouette
- can work as:
  - standalone mark
  - mark + wordmark
  - square app icon
  - monochrome version

### Visual tone keywords

- trust
- precision
- intelligent savings
- comparison
- modern finance
- restrained crypto-native

### Preferred formal qualities

- bold but not heavy
- minimal but not empty
- premium but not luxury
- technical but still friendly

## 7. Explicit creative routes worth exploring

### Route A — “Return path”
A symbol built from:
- a loop / return arrow / routed path
- implying fees coming back to the user
- maybe integrated with a subtle `C` or `R`

Why this route works:
- directly maps to rebate
- easy to animate later
- strong icon potential

### Route B — “Compare then choose”
A mark showing:
- split columns / dual lanes / comparison bars / branching path
- one route highlighted as the better choice
- subtle indication of optimization or savings

Why this route works:
- distinguishes the product from generic cashback brands
- reinforces the site's comparison-first utility

### Route C — “Shielded savings”
A mark that combines:
- trust / verification shape
- with an upward or returning movement
- without becoming a cliché shield logo

Why this route works:
- better for conversion trust
- useful if the brand leans more editorial / review / verification

## 8. What to avoid

Do **not** use any of the following as the main idea:
- generic bitcoin “B” marks
- rockets / moons / charts shooting up
- coins raining down
- casino-style trading visuals
- loud neon cyberpunk aesthetics
- overcomplicated gradients
- exchange-like logos that could be confused with Binance / OKX / Bybit / KuCoin etc.
- mascot direction
- anything that feels scammy, aggressive, or “airdrop farming” flavored

## 9. Color direction

### Keep
- trust-led blue family is still valid
- small accent color for “rebate / highlight / gain” is acceptable

### Evolve
Current palette is usable, but should be refined toward a more premium and less template-like system.

Suggested direction:
- Primary: deep brand blue / cobalt / trust blue
- Secondary accent: warm gold, lime, or bright cyan only if it clearly improves recognition
- Neutral support: white, near-black, slate

### Color principles
- must look good on white and dark backgrounds
- must still work in one color
- favicon must remain legible at 16px / 32px

## 10. Typography direction for wordmark

Wordmark should feel:
- clean
- modern
- product-grade
- not overly futuristic
- slightly condensed or tightly spaced is okay if readability stays high

Possible treatment:
- `CryptoRebate` in one line
- emphasize `Rebate` subtly through weight or color only if it still feels premium
- avoid gimmicky letter replacements unless they materially improve memorability

## 11. Deliverables expected

Please produce:

1. **3 distinct logo concepts**
   - each with a short rationale
   - each tied to a different strategic route

2. For the selected concept, provide:
   - primary full-color logo
   - monochrome black version
   - monochrome white version
   - icon-only version
   - favicon/app-icon safe version
   - horizontal lockup
   - clear space + minimum size guidance
   - color palette values
   - font recommendation or outlined wordmark

3. Optional but strongly preferred:
   - sample header mockup on website nav
   - sample favicon preview
   - sample dark-mode application

## 12. Practical constraints

- Must scale well for web navbar usage
- Must remain identifiable in a tiny favicon
- Should fit a modern SaaS/product UI
- Should not depend on fine detail to be understood
- Should work in SVG first

## 13. Success criteria

The redesign is successful if:
- the logo feels more memorable than the current one
- it increases perceived trust and product quality
- it better communicates “smart rebate comparison” rather than generic crypto branding
- it works equally well in navbar, social preview, and favicon contexts
- it is simple enough to become a stable long-term identity

## 14. One-line creative brief

> Design a logo for CryptoRebate that makes the brand feel like a trustworthy, modern, comparison-first crypto fee savings product — not a noisy affiliate site.

## 15. Notes for AI image/logo generation tools

If using an AI design model, use prompts biased toward:
- minimal vector logo
- modern fintech / SaaS brand system
- crypto-adjacent but non-speculative
- strong silhouette
- high contrast
- favicon legibility
- no mockup-only output; prefer flat vector-style presentation first
