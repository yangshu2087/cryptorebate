# CryptoRebate Logo Generation Prompts

基准 brief：
- `./logo-redesign-brief.md`

目标：给 AI 图像 / logo 生成模型 / 设计协作工具直接使用，先快速出 3 个方向，再人工筛选。

---

## 方向 A：Return Path / 返还路径

### 中文 prompt
设计一个 **CryptoRebate** 的现代极简品牌 logo。品牌是一个“加密货币交易所返佣比较平台”，核心价值是“先比较返佣，再注册，更长期地节省手续费”。

要求：
- logo 要体现 **返还 / 回流 / savings back / rebate** 的感觉
- 可以融合 **回路、回返箭头、路径、C 或 R 的抽象结构**
- 风格偏 **现代 SaaS / fintech / product brand**，不是投机炒币风
- 要有 **可信、清晰、克制、全球化互联网产品** 的气质
- 不要做成交易所 logo，不要像币种 logo，不要像低质返利站
- 不要使用比特币 B、火箭、暴涨 K 线、硬币雨、霓虹赛博风
- 图形要 **适合 favicon / app icon / navbar**，轮廓要强、细节不能太碎
- 输出倾向：**flat vector logo, strong silhouette, minimal geometry, premium blue palette with subtle accent**
- 白底优先，同时给出深色背景适配感

关键词：
minimal vector logo, fintech brand identity, trusted, clean, intelligent savings, return path, rebate, modern web product, favicon friendly

### English prompt
Design a modern minimal logo for **CryptoRebate**, a crypto exchange rebate comparison product. The brand promise is: **compare rebates before registering, so traders save more on fees over time**.

Requirements:
- express the idea of **rebate, return flow, cashback, fees coming back**
- may integrate a **loop, return arrow, routed path, abstract C or R**
- style should feel like a **modern SaaS / fintech / product brand**, not speculative crypto hype
- should feel **trustworthy, clear, restrained, web-native, globally usable**
- do not make it look like an exchange logo, token logo, or spammy affiliate site
- avoid bitcoin B, rockets, moon, aggressive charts, raining coins, neon cyberpunk aesthetics
- must work for **favicon, app icon, navbar, monochrome SVG**
- prefer **flat vector presentation, strong silhouette, minimal geometry, premium blue palette with a subtle accent**

Keywords:
minimal vector logo, trusted fintech, rebate, return path, fee savings, modern web product, favicon legible, flat brand mark

## 方向 B：Compare Then Choose / 比较后选择

### 中文 prompt
为 **CryptoRebate** 设计一个极简 logo。这个产品不是普通返利站，而是一个帮助用户 **比较不同交易所返佣、费率、邀请码与 KYC 条件** 的决策工具。

要求：
- logo 要体现 **比较 / 双列 / 分叉路径 / 选择更优路线 / 优化决策**
- 图形可以来源于 **双栏、分流、对比条、比较面板、路由结构**
- 需要保留 **省钱 / rebate / 更优选择** 的隐含含义
- 视觉风格：**清晰、理性、可信、产品化、略带科技感但不要炫技**
- 避免做得像价格比价网站、广告联盟站、交易所 banner
- 图形必须简单，适合 16px favicon 识别
- 输出以 **vector / brand system / icon-first** 为主

关键词：
comparison-first, decision tool, side-by-side, optimized route, trusted product, minimal symbol, clean fintech identity

### English prompt
Design a minimal logo for **CryptoRebate**. This is not a generic cashback site — it is a decision tool that helps users compare exchange rebates, fees, invite codes, and KYC requirements before signup.

Requirements:
- express **comparison, dual columns, branching paths, better choice, optimized route**
- visual source may come from **split panels, comparison bars, dual lanes, structured routing**
- should still imply **savings, rebate, or choosing the more efficient option**
- style: **clear, rational, trustworthy, product-grade, slightly technical but not flashy**
- avoid looking like a coupon farm, ad affiliate site, or exchange marketing page
- keep the symbol simple enough for **16px favicon recognition**
- prefer **vector, icon-first, brand system ready** output

Keywords:
comparison-first logo, decision tool, optimized route, modern fintech brand, minimal symbol, trusted product UI, favicon safe

## 方向 C：Trusted Savings / 可信省钱

### 中文 prompt
为 **CryptoRebate** 设计一个现代品牌 logo，重点强化 **信任感 + 节省手续费**。它服务的是加密交易用户，但品牌不能太“炒币味”。

要求：
- logo 可以结合 **可信 / 校验 / 稳定 / 保护** 与 **回返 / 省钱 / 优化** 两组概念
- 如果使用 shield-like 结构，必须做得更抽象、更现代，不要俗套盾牌
- 适合放在产品导航栏左上角，看上去像一个真正的长期品牌
- 风格克制、专业、现代、国际化
- 色彩以 **深蓝 / cobalt / trusted blue** 为主，可带极少量亮色点缀
- 必须兼容：白底、深色模式、单色版
- 不要 token、不要 meme、不要 exchange clone

关键词：
trusted savings, verification, reliable product brand, premium minimal logo, blue fintech, web-native, scalable SVG

### English prompt
Design a modern brand logo for **CryptoRebate**, emphasizing **trust + fee savings**. The audience is crypto traders, but the brand should avoid looking overly speculative or hype-driven.

Requirements:
- combine ideas of **trust, verification, stability, protection** with **return, savings, optimization**
- if using a shield-like structure, keep it abstract and modern rather than cliché
- should look credible in the top-left of a product navbar and feel like a long-term digital brand
- restrained, professional, modern, international tone
- color direction: **deep blue / cobalt / trusted blue**, with only a very small accent if needed
- must work on white, dark mode, and monochrome
- avoid token aesthetics, meme visuals, or exchange-like clones

Keywords:
trusted savings, verification, reliable fintech brand, premium minimal logo, scalable SVG, modern web identity

## 通用负面约束 / Negative Prompt

可附加在所有 prompt 后面：

- no bitcoin symbol
- no coin mascot
- no rocket
- no moon
- no candlestick chart explosion
- no gambling aesthetic
- no scammy affiliate look
- no overly detailed illustration
- no 3D mockup-only presentation
- no glossy token icon style
- no exchange logo imitation
- no crowded composition
- no tiny unreadable details

---

## 推荐出图流程

1. 每个方向先出 **8-12 个 icon-only 概念**
2. 从中筛到每个方向 **1-2 个候选**
3. 再要求模型补：
   - horizontal lockup
   - monochrome version
   - dark mode version
   - favicon preview
4. 最后再让模型做品牌应用 mockup，而不是一上来只出场景图

---

## 二次筛选标准

优先保留满足以下条件的方案：
- 16px 还能认出来
- 黑白版仍成立
- 第一眼不像交易所 logo，也不像空气币 logo
- 看起来像“可信工具型产品”
- 能支持后续网站 header / favicon / social card / app icon 统一使用
